# lingxing_dataviews

Resolve cross-page data access and extraction challenges of Lingxing ERP systems to facilitate rapid data aggregation and visualization.

## 领星跨页面字段库（正式版）

功能参考基线：**v1.4.72**。本仓库不包含内部版本归档、真实验收截图或浏览器缓存；历史私有备份应独立保存，不上传 GitHub。

当前版本：v1.4.81。含 MSKU 的领星 ERP 表格仍可作为主表和来源；匹配涉及 Listing 时，改用 ASIN＋店铺＋站点，来源搜索框也选择 ASIN。其他跨页字段保留 MSKU＋店铺＋站点规则。自动打开或复用来源页查询并回填，无需先手动查询。销量来源始终用干净临时页，验证目标日期后读取完整业务列；其余缺失项按本批 ASIN 或 MSKU 搜索。连续未命中按 30 秒至 5 分钟的退避间隔继续补查，并保留失败原因。

本目录可独立运行，不依赖其他项目或本机业务数据。文档与测试使用虚构店铺、商品和单号，不能作为真实经营数据使用。

## GitHub 上传与隐私

运行 `npm run privacy:check` 检查发布文件，再运行 `npm run export:github` 生成独立上传目录 `dist/github/` 及带校验值的源码 ZIP。**只上传 `dist/github/` 内的文件**，不要上传上级工作目录、旧安装包、稳定版本、截图、验收记录或浏览器数据。

导出使用文件白名单，不复制 `.git`、环境变量文件、账号会话或本机缓存。导出目录没有旧 Git 历史；请用它建立新仓库。如果此前已经上传过敏感内容，新提交或 `.gitignore` 不能消除旧提交与下载副本，需另行处理历史；泄露的凭据需要撤销并更换。

此处脱敏针对发布文件，**不改变插件的业务匹配规则，也不清空正在使用的缓存或阈值**。使用插件后仍会在本机保存真实 ERP 业务数据，不应将浏览器资料目录或缓存导出文件公开。数据范围、权限和限制见 [隐私说明](PRIVACY.md)。

## 工作方式

- 销量统计含 MSKU 的业务表在原生“FBA可售”列后自动增加“在途数量”：读取原库存下拉中的“标发在途”，保留零值；读取同页网络响应和已载入业务行的明确库存字段，不要求逐行点开原生明细。缺少来源数值显示“待读取”，不冒用 FBA 可售、计划入库或其他店铺库存。
- 点击销量“在途数量”沿用产品表现的近 6 个月 SHIPPED 完整货件快照及相同查询流程；只按完整 MSKU＋店铺匹配。销量下拉精简为“预计到货日期、在途数量”两列，日期正序，同日只一行，底部附总计；每票商品数量＝申报量－签收量。同一发货单关联多个 FBA 货件时，逐 FBA 货件求差再相加，不取整单发货量、不因同单号漏计。US 读取系统预计日；CA/UK/DE 按普船 +60 天、加班船 +30 天、空派 +14 天；历史已确认的铁路 +60 天及 MX 系统日期规则保持不变。没有日期归“待确认”且保留数量，不猜测、不丢弃；未读全不提供伪总计。再次点击、点击外部或 Escape 可收起，产品表现保留原五列明细。
- 涉及 Listing 的两个方向都用完整 10 位 ASIN，不依赖 MSKU 拼写，不回退 MSKU 或父 ASIN；搜索与最终回填使用相同键。已知店铺/站点必须一致。同店铺同站点同 ASIN 有多条 MSKU 时，只有目标字段完全一致才复用，价格冲突显示未命中，不任取一条。缺少有效 ASIN 的行明确提示无法补查。
- 销量统计默认新增“产品表现.FBA可售天数预估”跨页列，并在常用字段中置顶；首次启用后可自行移除，刷新不强行加回。无需先手动采集产品表现即可自动补查，按完整 MSKU、店铺、站点及目标报表日期匹配。来源读取整页已载入列，不要求先横向滚动到 FBA 预估列；非 MSKU 汇总视图不作为逐商品数据。
- 在销量统计面板为“FBA可售天数预估”单独编辑过短/过长界限：低于下限标红，高于上限标黄，等于界限不着色；留空关闭相应预警，未知或非数值不着色，零值正常参与比较。界限按当前页面保存，刷新继续保留；与产品表现里“销量统计.可用库存可售天数”的界限互不影响。新增列未设置阈值前不自动预警。
- 预警底色仅应用于扩展添加的单元格，并排除父 ASIN 等分组展开行自带的背景图层；切换视图后仍保持短天数红底、长天数黄底。正常值、阈值边界和未命中保持中性底色，不影响原生列或改动用户阈值。
- 产品表现面板独立显示“订单毛利率”界限编辑框，不需要先拖入跨页字段。按百分数输入（10 代表 10%，支持负值）：原生订单毛利率低于下限时红底预警，高于上限时黄底高亮；等于界限、未知或非百分比文本不标色。两个界限默认空白，可分别留空关闭，保存后刷新继续保留，原有天数阈值互不影响。仅标记精确名称“订单毛利率”的原生数据单元格，不影响订单毛利润金额、合计或原始数据；滚动、切换视图和阈值变更时重新核对，移除预警后恢复原生样式。
- 产品表现面板独立显示“ACoAS”上限编辑框（10 代表 10%）：原生 ACoAS 高于上限时红底预警，相等、空值或未知文本不标色；留空关闭。只识别 ACoAS，不改 ACOS、ASoAS、订单毛利率或金额列；上限独立保存并在刷新后恢复，旧页面保存布局不擦除该设置。
- “其他字段”支持即时搜索：可输入字段名、来源页或用空格分隔多个关键词，英文不区分大小写，显示匹配数量及无结果提示，点击“清空”恢复全部。常用字段与已添加列不受影响，搜索不改来源页查询条件，不删除字段或缓存；结果仍可拖拽。输入时不重建卡片，面板后台重绘保留搜索词、焦点与光标，中文组合输入期间延后重绘。搜索仅在当前页面会话使用，不永久保存。
- 搜索中的批量全选只勾选可见字段（含始终可见的常用字段），不勾选被搜索隐藏的列；先前显式勾选的筛选外字段仍保留，提示其数量，最终删除仍需原确认步骤。
- 销量与产品表现可以互为来源，来源工作页执行查询期间不派生反向补查，避免循环打开查询页。既有销量日历、货件整表快照及 v1.4.72 正常参考归档保持不变。
- 产品表现初始搜索类型为“品名”时，也能识别并定位下拉框；涉及 Listing 时切换 ASIN，其他情况切换 MSKU。输入组件提交完整查询值并确认渲染后才 Enter；每项查询前验证实际类型，不以 SKU 等其他类型代替。
- 产品表现横向滚动导致店铺/国家列移出虚拟表格时，保留同一表格、筛选范围、业务行编号及完整 MSKU 已读到的店铺身份；换页、改日期或筛选条件即失效，不从其他同 MSKU 行借用店铺。销量回填与货件点击共用此身份。
- 货件回访先重算展开后的现有布局，再定位目标行；虚拟滚动高度变化时重新划定定位范围。仍须看到真实展开/收起控件并核齐所有商品才保存完整快照。
- 已退场或透明度为 0 的加载遮罩不再阻塞来源结果保存，避免后台页延迟清理动画导致反复空等；真实可见加载层和业务 loading 仍阻止采集。
- 补查任务的小型登记写入会话存储，后台回收后恢复原请求和原截止时间；来源页每 5 秒回执。后台 70 秒无结果结束，主表另有 75 秒独立兜底，迟到的旧消息不会覆盖新任务。“重新扫描”会取消旧补查后重试。搜索词经输入组件提交并确认渲染后才送出 Enter；候选序号及单次等待范围明确显示。
- 货件回访先用表格定位接口；变高的虚拟行导致目标不在真实窗口时，按业务行索引二分校正滚动，再取最新控件。失败提示包含货件、行编号、目标及窗口索引，不再只显示“仍有待展开”。
- 销量搜索栏切换 MSKU 优先使用其原生选项处理函数，提交后核对实际选择值；接口不支持时回退 DOM 点击。货件展开后“收起”控件会移动到新增商品末尾，扫描后按业务行编号回访，只确认真实收起状态，不把点击过或节点消失视为完整。
- 当前打开的领星 ERP 表格页面只要有 MSKU 列，就可以成为主表；Listing 和销量统计的原有缓存继续沿用。
- 兼容新版 Listing 的 `ak-table-list` 表头/表体分离结构；SPA 切页时会重新确认当前路由，避免上一页名称和布局残留为当前主表。
- 重新打开或刷新领星页面、扩展更新或重载时均保留已采集的来源数据；当前可见行按复合键增量覆盖旧值，其余缓存继续用于跨页匹配，避免同一 MSKU 反复补查。需要清空时使用扩展弹窗中的明确清理操作。
- 插件持续读取当前表格的列名和当前可见行，并按来源登记到字段库。
- 当副表具有报表日期范围、主表没有同口径日期时，字段库面板显示该副表的开始/结束日期栏；自动补查先将来源页切换到所选日期，回填只使用同日期范围的数据。Listing 的“创建时间”不会被误当成销量统计日期。
- 销量统计优先通过原生日历的 focus、pick 及关闭面板生命周期提交日期，不手动替代业务 change，也不与货件共用日期模型提交。接口不可用才模拟点击；必要时临时显示来源页操作日历，结束后在来源仍活动时恢复主表，不抢走用户自行切换的焦点。先固定 MSKU 视图与搜索类型，再改日期并直接输入 MSKU、Enter 搜索；不点击表格刷新或等待整表刷新，结束不清空搜索词重搜。只有日期列已对应目标范围才批量读取，否则直接逐项搜索并验证结果日期。只有目标日期正确的业务结果才会保存。
- 字段库展示已采集的含 MSKU 表格字段。拖入当前主表后，涉及 Listing 按 ASIN＋店铺＋站点，其他字段按 MSKU＋店铺＋站点附加到当前表。
- 字段库将“销量统计·可用库存可售天数”“Listing·价格”“Listing·优惠价”固定在常用字段区；其他字段独立滚动，可用滚动条、上下按钮或拖拽靠近边缘滚动。常用字段仅置顶，不会自动加入主表。
- 产品表现主表拖入“销量统计·可用库存可售天数”后，面板显示过短和过长天数阈值（留空则不启用对应规则）。小于过短值的该列单元格标红，大于过长值标黄；等于阈值、未命中和非数值不着色。阈值随产品表现布局保存在本地，刷新后仍有效。
- 产品表现 MSKU 表在原生“FBA可售”列之后自动显示“FBA标发在途”。扩展优先从领星当前页数据响应读取该字段，按 MSKU、店铺与日期匹配，包含 0；不再自动打开明细或聚焦各行。用户自行打开的原生明细仍可回填，匹配不明确时显示“待读取”，不会误用其他行的数值；不会提交任何业务写操作。
- 点击“FBA标发在途”单元格后，插件抓取货件页近 6 个日历月的全部 SHIPPED 货件，拆成不重叠的自然月窗口，核对每页货件和逐商品数据。扫描结合可见行展开与整页已载入业务数据：票数、逐商品票数一致，待展开和未知行均为 0，状态、数量、店铺有效时，直接使用全部业务数据，不强求虚拟视口逐像素到底。显示“收起”的原生控件登记为已完成展开，跨视口保留，但新日期行对象不沿用旧证明。虚拟窗口重排时回退小步扫描而非仅凭行号硬失败；业务表仍有待展开或未知行则不缓存。记录票数、商品行、滚动位置、步数和耗时；连续 30 秒无表格进展会明确中止，单页及整轮仍有安全期限。日期和分页变化后等待新数据稳定，货件和逐商品数据核齐才缓存。首次完整抓取后，按完整 MSKU＋店铺从本次浏览器会话快照匹配后续明细。每票该商品在途量按“申报量－签收量”计算；预计同一天到货的货件合并为一行，列出票数、数量、发货单号与发货时间，并在底部显示筛选范围内的总计。US/MX 取系统预计到货日；所有其他站点根据发货时间和明确的物流渠道计算（普船/铁路 +60 天、加班船 +30 天、空派 +14 天）。日期依据不足时归为“待确认”，不猜测。分页或产品表格未读全时不提供伪总计。该合计与领星库存明细的标发在途可能口径不同，不会覆盖原列。
- 整表抓取先确认网络监听，再逐段设置创建时间和 500 条/页；接口缺少完整单品或发货单信息时，临时显示货件页读取虚拟滚动表。任务登记信息保存在会话存储，后台 Worker 回收后可恢复，周期回执只更新诊断而不覆盖真实阶段。发货单读取逐票显示进度，等待懒加载弹层实际数据并取得完整单号和日期，核齐目标后立即结束。查询结束自动切回产品表现页；仅完整快照保存在浏览器会话缓存，浏览器或插件重启时清除。任一窗口未核对完整都不缓存。
- “当前主表已添加字段”支持拖到指定字段的前后位置重新排序，保存后主表附加列同步换序；刷新页面后继续保留该页面的字段顺序。
- 拖动字段期间暂停面板整体重绘，并忽略鼠标仍在投放区内部时产生的 `dragleave`，松手后一次性刷新，避免字段和投放区反复抖动。
- 拖动经过已添加字段时，只有目标字段或插入方向真正变化才切换插入标记；投放区仅在指针实际越出边界后取消高亮，消除 Chrome 连续 `dragover/dragleave` 引起的视觉闪动。
- 字段库每个字段右侧的 × 可删除该字段及其本地缓存值；删除会同步移除各主表布局中的该字段，并阻止后续自动扫描再次加入。面板“已删除字段”可恢复，恢复后重新扫描来源页即可重新采集。
- 字段库右上角的“批量删除”可同时勾选多个字段，也可全选；确认后一次性删除选中字段及其本地缓存值。每次最多 5,000 项，已添加在主表的字段也可批量选择。
- 非 Listing 的通用字段在上下文缺失且 MSKU 唯一时允许匹配，存在歧义显示未命中。FBA 可售天数预估列及 Listing 关联字段更严格：主表有店铺/站点时，来源必须有相同上下文，即使仅一个候选也不使用别店或缺少上下文的数据。非 Listing 字段仍保留完整 MSKU 校验及空格/连字符规范化。
- 已拖入字段未命中时，优先沿用非当前活动来源页的筛选条件；涉及 Listing 用 ASIN 查询，其他用 MSKU。没有可复用来源页则创建后台临时页，完成、失败或超时后关闭。销量来源始终用干净临时页；其他来源恢复原搜索条件。
- FBA 库存等固定列与滚动列分离的 VXE 表格会在局部重绘后复核并补回附加列；数据行按页面行标识和 MSKU 重新对应，不再只依赖 DOM 行号。
- FBA 库存的“仓库”值会解析为店铺和站点，例如 `DEMO-CA加拿大仓` 对应 `DEMO-CA / CA`；美国、加拿大等中英文站点名称会统一后再匹配，避免重复 MSKU 全部显示“未命中”。FBA 页使用 `SKU` 或 `FNSKU` 搜索模式时也能启动补查。
- 面板实时显示来源页补查进度、命中数量和最终未命中数量。为避免重复请求，同一批未命中数据 30 秒内不会再次补查。
- 自动补查每批最多 8 个 ASIN 或 MSKU（销量来源每批最多 6 个）；先读取已载入行，再搜索缺失项。每个查询最多等 8 秒，整批最多 52 秒；等待加载结束、内容稳定才采集，超时明确停止。
- 自动补查仅识别当前可见搜索栏的类型、模糊/精确及关键词控件，包含 ASIN、MSKU 和默认品名；不把其他输入框当作搜索框。
- 销量来源自动切到逐 MSKU 业务视图；搜索条件按本批匹配键选择 ASIN 或 MSKU，每项前再次确认。临时页结束不清空重搜，避免额外查询重置日期；切换失败明确报错。其他来源恢复原筛选条件。
- 补查向搜索框提交 Enter；领星当前搜索图标可能只是装饰节点。若未检测到任何加载或表格变化，会明确报错且不消耗“连续未命中”次数。
- 不涉及 Listing 时，产品表现来源直接选择 MSKU 并输入完整值，保留站点后缀，不用 SKU 或短词；涉及 Listing 则选择 ASIN 并提交完整 ASIN。后台新页先通过 URL 确定来源，再就绪逐 MSKU 业务表和本批搜索类型。
- 未命中字段由后台来源页自动筛查；即使连续两次仍未命中，也会在冷却后继续自动重试，无需先去来源页手动查询。重试间隔逐步增加至最多 5 分钟，避免持续高频请求；“重新扫描”可立即清空冷却记录。
- 正式版默认只读，不提供调价或其他业务写操作。
- 字段数据保存在 `chrome.storage.local`，货件快照保存在本次浏览器会话的 `chrome.storage.session`，不发送到第三方。

## 安装顺序

更新已有插件时，替换完整目录，在扩展管理页点击“重新加载”，再刷新领星页面。v1.4.60 新增了主世界业务表读取脚本，仅刷新领星页面不足以更新扩展的脚本清单。

1. 在 `chrome://extensions` 加载本目录 `lingxing-field-merger/`。
2. 刷新需要使用的领星 ERP 表格页面，让插件记录当前页字段。表格需有 MSKU 列。
3. 如需跨页字段，至少打开过相应的含 MSKU 来源页，让插件识别字段名；不必在来源页逐个手动搜索或登记 MSKU。
4. 停留在哪个页面，哪个页面就是主表；打开右侧“字段库”，拖入需要的字段。

字段库记录的是已经在页面出现过的当前可见数据。切换分页或筛选后，插件会增量合并新出现的记录与字段，最多缓存每个来源 1,000 行。

## 版本归档

以后每次功能代码改动都先提升 `manifest.json` 与 `package.json` 的版本号，并在 `CHANGELOG.md` 增加对应版本说明。然后运行 `npm run release`：测试与静态检查通过后，脚本才会在上级目录生成 `领星跨页面字段库正式版-v版本号.zip` 和同名 `.sha256` 校验文件。脚本不会覆盖已存在的版本归档。旧版本压缩包保留，可用于回溯或回退。
